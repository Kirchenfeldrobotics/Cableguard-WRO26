# Raspberry Pi 5 Pin Legend
The document contains all the used RPI pins and maps them to its corresponding cable as follows: 
Description of cable purpose: RPI pin; cable legend 

## PINS
### Stepper
* Stepper GND: 6; 000
* Motion Stepper PUL: 12 (GPIO 18); 013
* Motion Stepper DIR: 16 (GPIO 23); 012
* Camera Stepper PUL: 32 (GPIO 12); 023
* Camera Stepper DIR: 36 (GPIO 16); 022

### Buttons
* Button GND: 30; 071 
* Start Button SIG: 29 (GPIO 5): 070
* Stop Button SIG: 31 (GPIO 6): 080

# Buzzer
* Buzzer SIG: 37 (GPIO 26): 101

# I2C 
* I2C GND: 9; 004 
* I2C Vin: 1; 003 
* SDA: 3; 001 
* SCL: 5; 002
